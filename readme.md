# Portfolio EJS

A lightweight portfolio website built with Node.js and EJS templates. This project is designed to showcase your work, skills, projects, and contact information in a clean and modern layout.

## Features

- Responsive portfolio layout
- EJS-based templating for easy content updates
- Section for projects, skills, and about information
- Contact section with links and social profiles
- Simple Express server setup

## Tech Stack

- Node.js
- Express
- EJS
- CSS
- JavaScript

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/Portfolio-Ejs.git
cd Portfolio-Ejs
```

2. Install dependencies:

```bash
npm install
```

## Running the App

Start the development server:

```bash
npm start
```

Then open your browser and visit:

```text
http://localhost:3000
```

## Customization

Update the content in the EJS templates and styles to match your personal brand:

- Edit `views/index.ejs` for page content
- Update `public/css/` for styling
- Modify your data in the Express app or template variables
